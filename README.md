# Blind Indoor Navigation System

## Introduction
The Blind Indoor Navigation System is a software-based application designed to help visually impaired individuals navigate indoor environments. It provides route guidance, visual route highlighting, and voice-based navigation instructions.

## Objectives
- To provide indoor route guidance.
- To calculate the shortest path between two locations.
- To provide voice-based navigation instructions.
- To display the selected route on an indoor map.
- To improve accessibility through a simple user interface.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Dijkstra's Shortest Path Algorithm
- Web Speech API

## Features
- Indoor location selection
- Shortest route calculation
- Interactive indoor map
- Route highlighting
- Voice navigation
- Step-by-step instructions

## How to Run the Project

1. Install Python 3.
2. Open the project folder in VS Code.
3. Create and activate a virtual environment.
4. Install Flask:

   pip install flask

5. Run the application:

   python3 app.py

6. Open the following URL in your browser:

   http://127.0.0.1:5000

## Current Scope
This is a software prototype that uses a predefined indoor map. It does not currently use physical sensors, cameras, or hardware-based obstacle detection.
